# Дасти Гӯё — переводчик таджикского жестового языка

**Дасти Гӯё** («Говорящая рука») — бесплатный сайт, который помогает глухим и слышащим людям
в Таджикистане понимать друг друга. Глухой человек показывает жесты перед камерой, сайт
распознаёт их, показывает текст и озвучивает на таджикском. Слышащий отвечает текстом или голосом,
и глухой видит ответ крупными буквами.

**Зачем это нужно.** Переводчиков таджикского жестового языка мало, а помощь нужна каждый день:
в поликлинике, в магазине, в школе. Готовых программ для таджикского жестового языка нет.

**Честно о возможностях.** Модель знает только те жесты, которые записали пользователи. Жесты
нужно записывать вместе с носителями языка: глухими людьми и сурдопереводчиками.

**Приватность.** Видео обрабатывается в браузере и никогда не отправляется на сервер.
На сервер уходят только координаты точек рук (числа) и аудиозаписи слов.

## Структура

```
frontend/   сайт: Vite + чистый JavaScript, MediaPipe, TensorFlow.js

```

## Бэкенд: запуск локально (Windows)

Нужен Python 3.11 или новее.

```powershell
cd backend
python -m venv .venv
.\.venv\Scripts\activate
pip install -r requirements.txt

copy .env.example .env
# Откройте .env и впишите JWT_SECRET и FIRST_ADMIN_PASSWORD.
# Сгенерировать секрет:
```

- Аудиофайлы и модели хранятся в `backend/media/`.

### Формат примера жеста

Пример — это одна запись из 10–150 кадров. Каждый кадр — **132 числа**, по 66 на каждую из двух рук:

- форма руки: 21 точка × (x, y, z), считается от запястья и делится на размер ладони;
- положение запястья в кадре;
- размер ладони.

Если рук в кадре две, первой («главной») считается та, что левее в исходном кадре. Если какой-то руки нет,
на её месте стоят нули. Формулы одинаковые в `backend/app/services/features.py` и
`frontend/src/dataset/features.js`; что они дают одинаковый результат, проверяет тест.
Сервер принимает только конечные числа в диапазоне ±10.

### Как обучается модель

- Обучение запускается в фоновом потоке, сервер при этом продолжает отвечать.
- Каждому активному жесту с примерами нужно минимум **20 одобренных** примеров. Если меньше,
  сервер вернёт ошибку со списком таких жестов.
- Модель смотрит на **движение**: каждая запись приводится к 16 кадрам × 132 числа = 2112 входов.
  Сеть: 2112 → 256 → 128 → число жестов, построена на scikit-learn (MLPClassifier).
  Она экспортируется в формат TensorFlow.js (`model.json` + `weights.bin`), и браузер загружает её
  обычным `tf.loadLayersModel()`. Тяжёлый TensorFlow на сервере не нужен.
- Каждая запись при обучении дополняется случайными копиями: обрезка по времени, зеркальное
  отражение (чтобы понимать левшей) и небольшой шум.
- Точность проверяется на записях, которые модель не видела при обучении.

### Наша нейросеть и набор Slovo

Готового набора данных по таджикскому жестовому языку нет. Поэтому базовая модель обучена на
открытом наборе **Slovo** (SberDevices, русский жестовый язык, лицензия CC BY-SA 4.0): 25 бытовых слов,
498 записей. На **людях, которых модель не видела при обучении, она даёт 73,6% правильных ответов**.
Подробности — во вкладке «Дар бораи ИИ»: график обучения, точность по каждому слову, какие жесты модель путает.

Таджикский жестовый язык вырос из той же советской системы: многие жесты совпадают с русскими, но не все.
По словам Национального объединения глухих Таджикистана, у слов «салом», «ош», «нон», «туй», «доира»
свои, национальные жесты. Подписи слов на сайте — это перевод **значения** на таджикский, а не утверждение,
что жест таджикский. Таджикские жесты нужно записывать вместе с носителями языка во вкладке «Омӯзиш».

Как пересобрать базовую модель (например, чтобы добавить слова в список `WORDS`):

```powershell
cd backend
# 1. Точки рук Slovo (1,2 ГБ; скачивание можно продолжить с того же места)
curl.exe -L -C - -o data\slovo\slovo_mediapipe.json https://rndml-team-cv.obs.ru-moscow-1.hc.sbercloud.ru/datasets/slovo/slovo_mediapipe.json
# 2. Таблица с подписями: достаётся из архива на 16 ГБ без его скачивания
.\.venv\Scripts\python tools\fetch_slovo_annotations.py
# 3. Сборка: модель → frontend/public/models/base, записи для браузера → frontend/public/datasets
$env:PYTHONPATH = "."; .\.venv\Scripts\python tools\build_slovo_base.py
```

В наборе Slovo есть и буквы русской дактильной азбуки А–Я; они понадобятся для тренажёра на этапе 6.

### Таджикский голос

Голос — бесплатная нейросеть **Meta MMS-TTS для таджикского** (`facebook/mms-tts-tgk`, лицензия
CC BY-NC 4.0: можно для некоммерческих проектов). Она читает таджикскую кириллицу целиком (ғ ӣ қ ӯ ҳ ҷ).
Чтобы голос звучал приятнее:

- делаем паузы по знакам препинания;
- говорим чуть медленнее и с ровной интонацией;
- выравниваем громкость и делаем мягкие начало и конец.

Где сайт берёт голос:

1. Заранее озвученные файлы всех слов и быстрых фраз (`frontend/public/audio/tts`) — работают без интернета.
2. Сервер `GET /api/v1/tts?text=…` — для новых фраз. Готовые записи кэшируются в `backend/media/tts`.
3. Голос браузера, если в системе есть таджикский.
4. Если голоса нет — сайт просто показывает текст.

```powershell
cd backend
pip install -r requirements-tts.txt --extra-index-url https://download.pytorch.org/whl/cpu   # ~200 МБ
$env:PYTHONPATH = "."; .\.venv\Scripts\python tools\pregenerate_tts.py   # озвучить слова и фразы заранее
```

При первом запуске модель (~145 МБ) скачивается с Hugging Face. Без этих пакетов сервер тоже работает:
`/tts` отвечает понятной ошибкой 503, а сайт пользуется готовыми файлами.
- Публикация сравнивает точность новой модели с текущей. Если новая хуже, сервер вернёт ошибку 409;
  обойти проверку можно параметром `?force=true`.

### Ошибки

Любая ошибка возвращается в одном формате, с текстом на двух языках:

```json
{"code": "not_enough_samples",
 "message": {"tg": "Барои омӯзиш ба ҳар имо камаш 20 намунаи тасдиқшуда лозим аст.",
             "ru": "Для обучения нужно минимум 20 одобренных примеров на каждый жест."},
 "errors": [{"gesture_id": 3, "name_tj": "Об", "approved": 5}]}
```

### Что умеет сайт

| Вкладка | Что делает |
|---|---|
| **Ба имо** | Слышащий говорит в микрофон или пишет — **3D-аватар показывает это жестами**: слово за словом, с субтитрами и регулировкой скорости. Понимает формы слов («мехоҳам» → «Хостан») и русский язык. Слова без жеста остаются в субтитрах бледными. |
| **Тарҷума** | Распознаёт жесты и крупно показывает слово. Слова складываются в предложение по правилам (`public/data/phrases.json` + правила с сервера) и произносятся таджикским голосом. Есть быстрые фразы крупными кнопками. Ответ слышащего — микрофоном или текстом — показывается на весь экран. |
| **Омӯзиш** | Пошаговый мастер: записать свои жесты и «нет жеста», обучить модель в браузере, проверить. Записи уходят на сервер, если вы вошли; без сети копятся и отправляются позже. |
| **Машқ** | Тренажёр: сайт показывает жест анимацией, вы повторяете, модель проверяет. 10 раундов, баллы, рекорд. Если вы вошли, итог уходит в профиль (без сети — позже). |
| **Профил** (кнопка в шапке) | Регистрация и вход. **Мой вклад в ИИ**: сколько жестов записано, одобрено, на проверке, сколько записей уже вошло в опубликованную модель. **Мои знания**: сколько жестов из словаря вы знаете (по тренажёру: ≥ 60% правильных хотя бы по 2 попыткам), история игр, цвет каждого жеста — знаю / учу / трудно / новый. Баллы и уровни (Навомӯз → Шогирд → Ёрдамчии ИИ → Донанда → Устод) и таблица лучших. |
| **Дар бораи ИИ** | Точность модели на новых людях, устройство нейросети, график обучения, точность по каждому жесту. |
| **Идоракунӣ** (ссылка внизу) | Вход для волонтёров и администраторов: статистика, жесты, проверка примеров, фразы, обучение и публикация модели на сервере, пользователи. |

Кнопка с монитором в шапке включает **режим показа** для проектора: только видео, слово и предложение —
крупно. Выход — та же кнопка или Esc.

**Без интернета.** В собранной версии Service Worker (`public/sw.js`) сохраняет сайт, модель рук,
нейросеть жестов, набор для обучения, словарь и всю озвучку. Без сети сайт открывается, распознаёт жесты
и говорит. Значок в шапке показывает «Онлайн», «Бе сервер» или «Офлайн». После изменения списка
сохраняемых файлов увеличьте `VERSION` в `sw.js`.

**Какая модель используется:** своя, обученная в браузере → опубликованная администратором на сервере
(скачивается автоматически) → базовая из набора Slovo.

**Распознавание речи** (кнопка «Гуфтан») — это Web Speech API браузера. В Chrome звук для распознавания
обрабатывают серверы Google, и таджикский язык там почти не поддерживается. Тогда сайт предлагает русский
или ввод текста.

### 3D-аватар («Ба имо»)

- **Модели** — на выбор, кнопки слева вверху (выбор запоминается):
  - «Мард» и «Зан» — реалистичные люди из библиотеки [Microsoft Rocketbox](https://github.com/microsoft/Microsoft-Rocketbox)
    (лицензия MIT; `Male_Adult_08`, `Female_Adult_05`). Скелет 3ds Max Biped: у каждого пальца, включая
    большой, три сустава, есть кость челюсти (рот приоткрывается во время жестов);
  - «Классикӣ» — прежний аватар Ready Player Me из примеров Three.js (`examples/models/gltf/readyplayer.me.glb`).
- **Как добавить аватар Rocketbox** — `tools/rocketbox.html`: положите FBX и TGA-текстуры из папки аватара
  в `public/_rb/<Имя>/`, откройте http://localhost:5173/tools/rocketbox.html?name=<Имя> и сохраните GLB
  в `public/avatar/`. Конвертер переводит сантиметры в метры, переименовывает кости Biped в имена Mixamo
  (`RightHandIndex2` …), добавляет кончики пальцев и уменьшает текстуры до 1024 px (3–4 МБ на аватар).
  Затем добавьте аватар в `AVATARS` (`src/avatar/avatarStage.js`) и кнопку в `index.html`.
- **Откуда движения:**
  - записи рук глухих людей из набора Slovo — для каждого слова выбирается самая типичная запись;
  - собственные записи из «Омӯзиш» — они важнее, так аватар показывает и таджикские жесты, которые вы записали.
- **Как движение переносится на аватар** (`src/avatar/rig.js`):
  - запястье ставится в нужную точку обратной кинематикой «плечо → локоть → кисть»;
  - ладонь поворачивается по трём точкам руки;
  - каждая фаланга пальца ставится по направлению своего отрезка на записи (в системе координат ладони),
    в пределах суставов живой руки: палец не выгибается назад и не гнётся вбок в средних суставах —
    так ошибки распознавания не превращаются в невозможные позы;
  - поворот кисти вокруг оси предплечья делится между предплечьем и запястьем (иначе кожа на запястье
    перекручивается);
  - движение сглаживается.

  Отзеркаленные записи разворачиваются, поэтому аватар всегда жестикулирует как правша.
- **Текст → жесты** — `src/avatar/lexicon.js`: основы слов на таджикском и русском. Новые слова добавляются
  туда же.
- Three.js и модель (3–4 МБ) грузятся только при открытии экрана и сохраняются для работы без интернета.
- Проверка без камеры: http://localhost:5173/tests/avatar-test.html?words=Салом,Хона&times=0.5,1.0
  показывает кадры жестов в заданные моменты. Ещё параметры: `avatar=female`, `inset=1` (точки записи
  рядом — сравнить с пальцами аватара), `zoom=0.7` (крупный план кисти).

### Как записывать жесты и обучать модель (вкладка «Омӯзиш»)

1. **Записывайте вместе с носителями языка:** глухими людьми или сурдопереводчиком. Не придумывайте
   жесты сами: модель выучит ровно то, что ей показали.
2. Вкладка ведёт по шагам: камера → жесты → «нет жеста» → обучение → проверка. Текущий шаг подсвечен.
   Введите название жеста (например, «Салом») и нажмите «Записать». После отсчёта 3–2–1 покажите жест:
   записывается 75 кадров, это около 2,5 секунды. Повторное нажатие отменяет запись.
3. **Каждый жест записывайте 20 раз или больше:**
   - в разном темпе;
   - при разном свете;
   - на расстоянии 50–100 см;
   - лучше разными людьми.

   После каждой записи опускайте руки.
4. Обязательно запишите класс **«нет жеста»**: руки опущены, случайные движения, почёсывание.
   Без него сайт будет «видеть» жесты там, где их нет.
5. Раскройте жест в списке. Миниатюры показывают позу руки; неудачный пример удаляется кнопкой ×.
6. Нажмите «Обучить». Точность проверяется на записях, которых модель не видела.
7. После обучения показывайте жесты: строка «Проверка» показывает, что модель видит прямо сейчас.
8. Сайт предупреждает, если:
   - у жеста мало примеров;
   - два жеста слишком похожи;
   - модель их путает;
   - нет класса «нет жеста».
9. «Сохранить в файл» записывает примеры, модель и словарь в один JSON-файл.
   «Загрузить из файла» добавляет примеры к уже имеющимся, поэтому записи с разных компьютеров можно объединять.

Всё хранится в браузере (IndexedDB) и работает без интернета.

### Самопроверка без камеры

При запущенном `npm run dev` откройте http://localhost:5173/tests/selftest.html. Страница проверяет:

- нормализацию точек;
- запись;
- обучение в TensorFlow.js;
- сохранение, экспорт и импорт;
- что модель, обученная на сервере, даёт в браузере те же ответы.

Данные пользователя самопроверка не трогает.

## Известные ограничения

- Ограничение попыток входа хранится в памяти процесса. При нескольких процессах uvicorn
  нужен общий счётчик, например в Redis.
- Модель распознаёт отдельные кадры. Движение во времени учитывается на фронтенде: жест засчитывается,
  только если держится около 0,5 секунды.
- Точность сильно зависит от данных: нужны разные люди, разное освещение и разный фон.
- Сайт не видит лицо и тело, только руки. Поэтому жесты, которые отличаются только местом
  (у лба или у груди), модель различает плохо.
- Базовые жесты взяты из русского жестового языка. Сайт честно предупреждает об этом и отдельно
  помечает слова, для которых в таджикском языке есть свой жест.
- В наборе Slovo нет записей «нет жеста» с руками. Поэтому в базовой модели этого класса нет:
  от ложных срабатываний защищают проверка, что руки видны, порог уверенности 80% и требование,
  чтобы ответ повторился. Запишите свои примеры «нет жеста» и переобучите модель, чтобы стало надёжнее.
- 73,6% — это примерно 3 жеста из 4 у незнакомого человека. Модель может ошибаться, особенно
  при плохом свете или если руки не целиком в кадре.
- Распознавание лица и тела не сделано: в наборе Slovo есть только точки рук, обучить такую модель не на чем.
- Тренажёр учит жестам из набора Slovo. Таджикской дактильной азбуки (буквы ғ ӣ қ ӯ ҳ ҷ) пока нет:
  её нужно записать с носителями языка во вкладке «Омӯзиш» (тип «ҳарф» в админке).
- Ответ голосом зависит от браузера: Web Speech API есть в Chrome и Edge, таджикский язык он почти
  не распознаёт.
- 3D-аватар показывает только руки и пальцы. Тело, лицо и движения губ — общие, а не из записи:
  в наборе Slovo есть только точки рук. Мимика, важная в жестовом языке, пока не передаётся.
- Глубина движения рук (ближе/дальше от тела) оценивается по размеру ладони на видео,
  поэтому она приблизительная.
